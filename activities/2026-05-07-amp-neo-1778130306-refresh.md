## Context

Amp updated to `0.0.1778130306-g2889d9` (`released 2026-05-07T05:06:28.128Z`). Checked the local connector shim against the new binary shortly after release.

- Mode list remains `smart`, `deep`, `rush`, `large`.
- Configured MCP tools now show directly in `amp tools list --json --mode <mode>` for all four modes in this environment:

- Runtime WebSocket traffic seen during smoke still used the existing local shim messages: `client_update_thread_settings`, `executor_connect`, `client_resume`, `client_append_user_msg`, executor environment/guidance/skill snapshots, `executor_tools_register`, `executor_tools_bootstrap_complete`, and `executor_plugin_message`.
